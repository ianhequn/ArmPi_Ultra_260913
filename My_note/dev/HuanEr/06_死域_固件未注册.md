# 06 · 死域：有代码但固件不认

> **判断依据**：固件 `packet_handle_init()` 只注册了 4 个 func（LED / 蜂鸣器 / 总线舵机 / 电机）。
> 下面这些在 SDK / 节点里都有代码，但**发出去不会有效果**。

---

## 1. 固件的注册表（唯一判据）

`Hiwonder/System/packet_handle.c` L379：

```c
packet_register_callback(PACKET_FUNC_LED,        packet_led_handle);          ✅
packet_register_callback(PACKET_FUNC_BUZZER,     packet_buzzer_handle);       ✅
packet_register_callback(PACKET_FUNC_BUS_SERVO,  packet_serial_servo_handle); ✅
packet_register_callback(PACKET_FUNC_MOTOR,      packet_motor_handle);        ✅
// packet_register_callback(PACKET_FUNC_PWM_SERVO, packet_pwm_servo_handle);  ❌ 被注释
```

**`packet_pwm_servo_handle` 函数写好了，但没注册** → PWM 舵机命令无人处理。

---

## 2. 死域清单

| 域 | `func` | ROS2 接口 | SDK 方法 | 固件状况 | 结论 |
| --- | --- | --- | --- | --- | --- |
| **PWM 舵机** | `4` | sub `~/pwm_servo/set_state`<br>srv `~/pwm_servo/get_state` | `pwm_servo_set_position`<br>`pwm_servo_set_offset`<br>`pwm_servo_read_position`<br>`pwm_servo_read_offset`<br>`pwm_servo_read_and_unpack` | **handler 未注册**<br>（代码在 `packet_handle.c` L272） | ✗ 无效 |
| **OLED** | `10` | sub `~/set_oled` | `set_oled_text` | 固件无 handler | ✗ 无效 |
| **RGB** | `11` | — | — | 固件无 handler | ✗ 无效 |
| **传送带** | `12` | sub `~/set_conveyor_speed` | `set_conveyor_speed` | 固件无 handler | ✗ 无效 |
| **步进电机** | `13` | sub `~/set_stepper_subdivision`<br>srv `~/move_stepper` | `set_stepper_motor_position`<br>`set_stepper_motor_subdivision` | 固件无 handler | ✗ 无效 |
| **电机占空比** | `3` | — | `set_motor_duty`（sub `0x05`） | 固件 switch 只有 `0/1/2/3/0x20` | ✗ 无此 case |
| **`/joint_controller`** | — | `/joint_controller`（`servo_controller` 包） | — | 厂商回调有 bug | ⚠️ **勿用** |

> ⚠️ **PWM 舵机子命令是存在的**（固件代码里：`0x01` 多个 / `0x03` 单个 / `0x05` 读位置 / `0x07` 设偏差 / `0x09` 读偏差），
> 只是**分发入口被注释**。如果以后要用 PWM 舵机，需要改固件重新编译。

---

## 3. 为什么会有这些"死代码"

| 原因 | 说明 |
| --- | --- |
| **SDK 是一套、固件是另一套** | 同一个 Hiwonder SDK 服务多种板子（JetArm / JetRover / 传送带底盘…），本项目这块板只实现了子集 |
| **SDK 比固件新** | SDK 的 `PACKET_FUNC_NONE = 14`（有 OLED/RGB/传送带/步进），本固件 `NONE = 10` |
| 固件裁剪 | 板子上没有那些外设，编译时把注册注释掉了 |

---

## 4. 对我们的处理建议

| 优先 | 动作 |
| --- | --- |
| 1 | **标注而非删除**：这些接口在 ROS2 侧存在（`ros2 topic list` 能看见），直接删会让文档与现场不符 → 文档里标注 `✗ 固件不支持` |
| 2 | 若确实不用，可在**我们自己的网关/上层**忽略它们（不要转发到这些话题） |
| 3 | **不要试图改固件**：源码是 STM32F4 工程（Keil/CMake），改动需重编译 + 烧录，风险远大于收益 |
| 4 | 唯一可能有价值的：`set_motor_duty` 若哪天要用，需先核对固件的 sub 编号 |

---

## 5. 一句话

> **固件只认 4 个 func：LED、蜂鸣器、总线舵机、电机。**
> 其余 10 个 func 号（PWM舵机/按键/IMU/手柄/SBus 是**上报方向**，OLED/RGB/传送带/步进是**死域**）
> 中，只有上报方向的几路是活的。
> **机械臂控制只用到「总线舵机」一个域。**
