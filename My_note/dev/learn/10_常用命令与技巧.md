# 10 常用命令与技巧

> 速查表。

---

## 构建

```bash
colcon build
colcon build --packages-select <pkg>
colcon test --packages-select <pkg>
colcon test-result --verbose
source install/setup.bash
```

## 建包

```bash
ros2 pkg create <name> --build-type ament_python --dependencies rclpy --node-name <node>
ros2 pkg create <name>_msgs --build-type ament_cmake --dependencies std_msgs
```

## 运行 / 查看

```bash
ros2 run <pkg> <node>
ros2 launch <pkg> <file.launch.py> arg:=value
ros2 node list
ros2 node info <node>
ros2 topic list
ros2 topic hz <topic>
ros2 topic echo <topic> -n 1
ros2 service list
ros2 service call <srv> <type> "<args>"
ros2 interface show <pkg>/msg/<Type>
ros2 param list <node>
```

## 发布一条消息

```bash
ros2 topic pub --once /servo_controller servo_controller_msgs/msg/ServosPosition \
  "{duration: 0.5, position_unit: 'pulse', position: [{id: 6, position: 600}]}"
```

## 本项目启动速查

```bash
# 全部（driver + 网关 + 数据流）
ros2 launch arm_lerobot_dataset_stream arm_lerobot_dataset.launch.py release_torque:=true

# 只驱动
ros2 launch ros_robot_controller ros_robot_controller.launch.py

# 只网关
ros2 launch servo_controller servo_controller.launch.py

# 串口桥
ros2 launch arm_serial_bridge arm_serial_control.launch.py

# UDP 桥
ros2 launch arm_vofaUDP_bridge arm_vofa_control.launch.py
```

git status

## 小技巧

- 看消息定义：`ros2 interface show <type>`。
- 查节点参数：`ros2 param list <node>`。
- 打印及时刷新：`print(..., flush=True)`。
- 长命令用 `\` 换行，方便阅读。
- 工作区路径：`/home/u24/MyTest/dev01/ros2/test_ws01`。
