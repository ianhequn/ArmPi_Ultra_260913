# 01 官方建包与构建

> 目标：用**官方命令**建包，并让它在 `ros2 run` 里跑起来。
> 规则：**不手工建目录**，一律 `ros2 pkg create`（保证格式/lint 正确）。

---

## 步骤

### 1. 选构建类型

| 类型 | 用于 | 例子 |
| --- | --- | --- |
| `ament_python` | 纯 Python 节点 | `servo_controller`、`arm_serial_bridge` |
| `ament_cmake` | C++ / **消息定义** | `*_msgs` |

### 2. 建一个 Python 包

```bash
cd /home/u24/MyTest/dev01/ros2/test_ws01/src
source /opt/ros/jazzy/setup.bash
ros2 pkg create arm_demo --build-type ament_python \
  --dependencies rclpy --node-name demo_node
```
生成：
```
arm_demo/
├── arm_demo/demo_node.py     # 节点入口（可改）
├── arm_demo/__init__.py
├── package.xml               # 依赖声明
├── setup.py                  # 入口点 + 安装规则
├── setup.cfg
└── test/                     # copyright / flake8 / pep257
```

### 3. 建一个消息包

```bash
ros2 pkg create arm_demo_msgs --build-type ament_cmake --dependencies std_msgs
```
在 `msg/`、`srv/` 放 `.msg`/`.srv` 文件，然后在 `CMakeLists.txt` 里注册：

```cmake
rosidl_generate_interfaces(${PROJECT_NAME}
  "msg/MyState.msg"
  "srv/GetState.srv"
)
```
`package.xml` 加 `<build_depend>rosidl_default_generators</build_depend>` 和
`<member_of_group>rosidl_interface_packages</member_of_group>`。

### 4. 构建

```bash
cd /home/u24/MyTest/dev01/ros2/test_ws01
colcon build --packages-select arm_demo arm_demo_msgs
source install/setup.bash
```
预期：`Summary: 2 packages finished`。

### 5. 运行 / 查看

```bash
ros2 run arm_demo demo_node
ros2 interface show arm_demo_msgs/msg/MyState     # 看消息字段
ros2 pkg executables arm_demo                     # 看有哪些可执行
```

### 6. 两个关键文件

`setup.py`（Python 包）——**入口点**决定 `ros2 run` 的名字：
```python
entry_points={
    'console_scripts': [
        'demo_node = arm_demo.demo_node:main',
    ],
},
```

`package.xml`——**依赖**要写全（不然别的机器 `rosdep` 装不上）：
```xml
<depend>rclpy</depend>
<exec_depend>python3-serial</exec_depend>
```

---

## 原理（极简）

- 包名 = `ros2 run/launch` 里的第一段；**必须全小写**。
- `ament_python` 的 `setup.py` 负责"装哪些文件、有哪些可执行"。
- 消息包必须先构建，用它的节点才能 `import`。

## 常见坑

- **包名含大写**（如 `arm_vofaUDP_bridge`）：能用，但 colcon 会告警。
- `package.xml` 里 `test_depend` 要排在 `<member_of_group>` **之前**，否则 lint 报错。
- 改了 Python 代码 → **必须 `colcon build` 再 source**。
- `src/` 下别提交 `__pycache__`、`*.pyc`（已在 `.gitignore` 忽略）。
