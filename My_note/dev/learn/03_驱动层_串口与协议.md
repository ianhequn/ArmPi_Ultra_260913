# 03 驱动层：串口与协议

> 目标：打开串口，按厂商协议发一帧，让某个舵机动。
> 对应代码：`src/ros_robot_controller/ros_robot_controller/ros_robot_controller_sdk.py`

---

## 前提

| 项 | 值 |
| --- | --- |
| 设备 | `/dev/ttyUSB0`（CH340，按插入顺序） |
| 波特率 | `1000000` |
| 权限 | 当前用户在 `dialout` 组 |

## 协议帧

```
AA 55 | func | len | data... | crc8
```

| 段 | 字节 | 说明 |
| --- | --- | --- |
| 帧头 | 2 | 固定 `0xAA 0x55` |
| func | 1 | 功能号（`PacketFunction`） |
| len | 1 | data 长度 |
| data | n | 载荷 |
| crc8 | 1 | 对 `func..data` 算 CRC8 |

常用 func：

| func | 作用 |
| --- | --- |
| `0x00` | 系统（电池/IMU 等上报） |
| `0x04` | PWM 舵机 |
| `0x05` | **总线舵机**（本项目用的一类） |

**总线舵机 func 固定 `0x05`，具体操作由 data 的第 1 字节（子命令）决定**：

| 子命令 | 作用 |
| --- | --- |
| `0x01` | 设位置（带时长） |
| `0x05` | 读位置 |
| `0x0B` | **关**扭矩 |
| `0x0C` | **开**扭矩 |

> 例：`bus_servo_set_position` → func `0x05`，data = `[0x01, 时长低, 时长高, 个数, id, 位置...]`。

## 步骤

### 1. 直接用 SDK（**先关掉 driver**）

```bash
cd /home/u24/MyTest/dev01/ros2/test_ws01
source /opt/ros/jazzy/setup.bash && source install/setup.bash
python3 -c "
from ros_robot_controller.ros_robot_controller_sdk import Board
b = Board(device='/dev/ttyUSB0', baudrate=1000000)
b.enable_reception()                       # 直连必须先开接收
b.bus_servo_set_position(0.5, [[6, 600]])  # id=6，0.5s 转到 600（0~1000）
print('sent')
"
```
预期：打印 `sent`，舵机 6 转动。

### 2. 读舵机位置（**带超时兜底**）

读函数是阻塞的，用线程 `join(timeout)` 防卡死：
```python
import threading
res = {}
t = threading.Thread(target=lambda: res.update(pos=b.bus_servo_read_position(6)))
t.start(); t.join(1.0)
print('timeout' if t.is_alive() else res)
```

### 3. 走 ROS 读（推荐）

driver 起来后，用服务读，别直连串口：
```bash
ros2 service call /ros_robot_controller/bus_servo/get_state \
  ros_robot_controller_msgs/srv/GetBusServoState \
  "{cmd: [{id: 6, get_position: 1}]}"
```

## 原理（极简）

- **只有 `Board` 接触串口**，上层都调它。
- 写 = 组帧 + `serial.write`；读 = 后台线程收包，按 `AA55` 找帧、校验、入队。
- 读是**请求/应答**：发请求后等队列，所以必须先 `enable_reception()`。

## 常见坑

- 忘了 `enable_reception()` → 读永远拿不到数据。
- 读函数**无超时**：舵机没电/不回会**永久卡住**并占着锁 → 一定用线程兜底。
- 串口 `Input/output error`（EIO）：CH340 在虚拟机下掉线，等几秒或重新插拔。
- 串口同一时刻**只能被一个进程**占用（driver 和直连脚本不能同时开）。
